# Защита рабочего пространства

Браузер обращается только к нашему backend. Backend вызывает OpenRouter и получает
аудио с разрешённых доменов. Ключи, хеш пароля и исходные подписанные ссылки на
аудио не передаются браузеру. Само аудио доступно через защищённый endpoint.

## Реализовано

- Один пароль рабочего пространства, scrypt с солью. API не предоставляет смену пароля.
- Случайная серверная сессия; в SQLite хранится хеш токена. HttpOnly/SameSite=Strict,
  в production Secure и префикс `__Host-`. Время жизни до 8 часов по умолчанию,
  неактивность 30 минут; выход отзывает сессию. Смена хеша пароля инвалидирует сессии.
- Все прикладные API и аудио требуют входа. Публичны только минимальный health check,
  проверка сессии и вход. Документация API отключена.
- Проверка Host/Origin, отдельный CSRF-токен и служебный заголовок для изменений.
- Постоянные лимиты в SQLite: общий лимит запросов, ограничение попыток входа,
  3 платных запуска в минуту и 60 в час по умолчанию, максимум 2 одновременно.
- Ограничение тела до разбора JSON/multipart, включая запросы без Content-Length.
  Аудиофайл до 25 MiB; multipart-конверт до 26 MiB. Ограничены текст и размер импорта.
- Загрузка удалённого аудио только по HTTPS с разрешённых доменов; проверка каждого
  перенаправления и публичности всех DNS-адресов, соединение с проверенным IP и TLS SNI.
- CSP, защита от встраивания, nosniff, no-referrer, no-store для API; HSTS в production.
- Контейнер app без root, с read-only корнем, ограничениями памяти/процессов,
  без опубликованного порта. Секреты и данные исключены из Git и Docker build context.

## Границы

Это одно доверенное рабочее пространство с общим администраторским доступом.
Раздельных пользователей, прав и изоляции клиентов нет. Для нескольких организаций
нужны отдельные экземпляры либо полноценная модель доступа.

Апелляции и решения QA доступны всем вошедшим в это пространство. Имена автора и
проверяющего вводятся вручную и не удостоверяют личность. История переходов хранится
на сервере; исходные AI-оценки не меняются. Черновики форм живут в памяти браузера,
переходы с несохранёнными изменениями требуют подтверждения; тексты черновиков не
записываются в localStorage/sessionStorage.

Ограничение числа запросов не является денежным бюджетом: задайте лимит у провайдера.
Диалоги и аудио передаются внешним AI/STT-провайдерам при запуске обработки.
Автоматического обезличивания перед отправкой сейчас нет. Токены и расходы могут
быть доступны вошедшему администратору через API, хотя скрыты в интерфейсе.

Сервер хранит исходные диалоги, результаты и аудио. TLS защищает передачу;
шифрование диска и резервных копий, политика удаления и безопасность хостинга
настраиваются отдельно. Администратор хоста имеет доступ к данным и env-файлу.

Промпт рассматривает диалог как недоверенный текст; модель не имеет инструментов
для выполнения команд. Локальная проверка структуры и цитат не гарантирует
семантическую точность и не устраняет полностью prompt injection.

## Проверка

`backend/tests/test_security.py` проверяет вход/выход, отзыв сессии, CSRF, Origin,
ограничения запросов, ограничения тела, production-конфигурацию, утечку подписанных
URL и частные адреса при скачивании. Браузерная проверка проверяет отсутствие
внешних запросов frontend и недоступность cookie через JavaScript.

## Изученные примеры

- [FastAPI full-stack template](https://github.com/fastapi/full-stack-fastapi-template):
  ориентир для контейнерного запуска, серверных секретов и TLS-прокси.
- [Langfuse masking](https://langfuse.com/self-hosting/security/data-masking):
  маскировать данные следует до отправки внешнему сервису. Будущее обезличивание
  RU/KZ нужно отдельно проверить, чтобы не потерять доказательства идентификации.
- [Linewise](https://github.com/jpsoriaga/linewise): идеи настройки рубрик, работы
  с расшифровками и объяснений оценки. Это исследованный пример, не внедрённая зависимость.
- [Mentify](https://github.com/cnbjjj/mentify): расширение читает готовые ответы из API
  и выводит их в консоль. Движка AI-оценки нет. Для нас полезен вывод: скрытое в UI
  поле остаётся доступным пользователю, если сервер отправил его браузеру.

Код этих проектов не копировался. Расширение Mentify не устанавливалось и не запускалось.
